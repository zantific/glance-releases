# Foundific Glance downloads

Foundific Glance is a free teleprompter for Mac and Windows that is hidden from screen sharing.

Download it from https://foundific.com/apps/glance/. On Windows, get it from the Microsoft Store.

This repository holds the release files only, so installed apps can check for updates. It contains no source code.
